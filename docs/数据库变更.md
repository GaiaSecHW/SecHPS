# 数据库变更记录

## 2026-05-23

### AgentApp 新增 `requireCodedmap` 字段

- **表**: `AgentApp`
- **字段**: `requireCodedmap` — `Boolean`, 默认值 `false`
- **用途**: 标记 Agent 是否需要知识图谱。创建任务时，若选中的 Agent 均未开启此选项，则跳过 CodedMap 知识图谱构建，避免不必要的资源消耗。
- **迁移方式**: `prisma db push`（无破坏性变更）

### User 新增 `mustChangePassword` 字段

- **表**: `User`
- **字段**: `mustChangePassword` — `Boolean`, 默认值 `false`
- **用途**: 管理员创建用户时自动生成初始密码，并标记 `mustChangePassword = true`。用户首次登录后被强制跳转到个人中心修改密码，修改成功后自动清除标记。
- **迁移方式**: `prisma db push`（无破坏性变更）

### 清理无用角色

- **操作**: 删除 `viewer` 和 `manager` 角色
- **涉及表**: `Role`、`UserRole`
- **原因**: 精简角色体系，保留 admin、developer、user 三个角色
- **注意**: 需先清除 `UserRole` 中关联记录，再删除 `Role` 记录
