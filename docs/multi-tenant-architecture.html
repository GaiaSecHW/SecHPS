👤 用户角色层
PLATFORM ADMIN

平台管理员

系统级管理，无租户绑定，全量数据访问权限

tenantId = null roles: [admin]
  • 可访问所有租户数据
  • 可创建 public / private 资源
  • 可管理租户 CRUD 和用户分配
  • 查询条件：无过滤
ICSL TENANT

ICSL 特权租户

特权部门，拥有完整访问权限，可创建公共资源

isIcsTenant = true tenantId = icsl_id
  • 可访问所有租户数据
  • 可创建 public / private 资源
  • 不可访问租户管理 API
  • 查询条件：无过滤
REGULAR TENANT

普通租户用户

产品线部门，仅访问本租户 + 公共资源

isIcsTenant = false tenantId = xxx
  • 仅可见本租户 private + 所有 public
  • 不可创建 public 资源
  • 不可访问租户管理 API
  • 查询条件：tenantId OR isPublic=true
