## 1. 系统总体架构

### 1.1 技术栈概览

```
┌─────────────────────────────────────────────────────────────────┐
│                    SecHPS 测试平台架构                           │
├─────────────────────────────────────────────────────────────────┤
│  前端层: Next.js 16 + React 19 + TypeScript App Router           │
│  认证: JWT + RBAC (基于角色的访问控制)                            │
│  数据库: SQLite + Prisma ORM v5.22.0                             │
│  服务层: 模块化业务逻辑封装                                        │
│  AI集成: Claude Agent SDK + MCP Server 协议                      │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 核心设计理念

- **反馈驱动进化**: AI 自动学习失败经验，形成闭环优化
- **精准率导向**: 以漏洞检测结果精准率为核心指标驱动 Skill 进化
- **智能治理**: LLM 深度分析技能重复，自动识别合并候选
- **威胁建模**: STRIDE 方法论 + FSM 有限状态机编排

### 1.3 数据库规模

- **表数量**: 60+ 业务实体表
- **索引优化**: 200+ 索引覆盖高频查询
- **关联关系**: 完整的级联删除与引用约束

### 2.2 权限模型

```
权限格式: module:action (模块:操作)

示例权限:
- skill-evolution:manage     # Skills 进化管理
- vulnerability:verify       # 漏洞验证
- user:create                # 用户创建
- project:delete             # 项目删除

角色预置:
- admin: 全权限
- manager: 项目管理权限
- developer: 执行权限
- user: 基础权限
- viewer: 只读权限
```

### 2.3 技术亮点

1. **双Token机制**: Access + Refresh Token，兼顾安全与体验
2. **缓存优化**: 权限查询结果缓存 5 分钟，减少数据库压力
3. **级联权限**: 用户 → 角色 → 权限三层关联，支持灵活配置
4. **环境隔离**: 服务端/客户端权限检查分离，避免环境变量泄露

## 4. Skills 进化模块 ⭐

### 4.1 模块概述

Skills 进化是本系统的核心创新功能，实现 **AI 自我优化闭环**：
- 监控 Skill 精准率 (Precision = 确认数 / 发现总数)
- 自动触发进化任务 (精准率 < 阈值)
- 反馈驱动重试机制 (最多 10 次，每次传递失败信息)
- 自动回测验证 (误报排除率 ≥ 50%，漏检数 = 0)

```

    │

    │       ├── attemptNumber: 1-10
    │       ├── falsePositiveCasesUsed: 使用的误报案例
    │       ├── confirmedCasesUsed: 使用的确认案例
    │       ├── improvedContent: 本次改进内容
    │       ├── backtestSummary: 回测结果
    │       ├── falsePositiveExclusionRate: 误报排除率
    │       ├── confirmedMissed: 漏检数
    │       ├── isPassed: 是否达标
    │       └── failureReason: 失败原因
    │
    └──▶ SkillEvolution (版本历史)
            ├── fromVersion → toVersion
            ├── beforeData → afterData
            └── beforeRate → afterRate
```

### 4.4 技术亮点

1. **反馈驱动重试**: 每次失败的信息传递给下一次尝试的 AI Prompt，形成学习闭环
2. **混合案例策略**: 失败案例必须包含，确保不会重复犯错
3. **严格达标标准**: 漏检数 = 0 + 排除率 ≥ 50%，双重保障
4. **版本追溯**: 完整的版本演进历史，支持回滚
5. **可配置阈值**: precisionThreshold、minFalsePositives、minConfirmed 全局可调

## 5. Skills 治理模块 ⭐

### 5.1 模块概述

Skills 治理实现 **智能重复检测与合并建议**：
- 快速检测：同语言 + 同漏洞类型的潜在重复
- LLM 深度分析：AI 判断技能是否真正功能重复
- 自动分组：形成重复组并推荐合并
- 人工审核：LLM 分析结果需人工确认
