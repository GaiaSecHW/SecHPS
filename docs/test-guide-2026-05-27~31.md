## 十、任务队列 FIFO 永久等待

**Commit:** `20175995`

### 自动化测试步骤

```
1. 确保 Worker maxConcurrent=1
2. 快速连续提交 3 个任务 → POST /api/task-builder/tasks/execute 3 次
3. 查询任务状态 → GET /api/task-builder/tasks?page=1
4. 第 1 个任务 → status 应为 running
5. 第 2、3 个任务 → status 应为 pending（排队）
6. 等待第 1 个完成 → 第 2 个变为 running
7. 等待第 2 个完成 → 第 3 个变为 running
```

### 验收规则

| # | 检查项 | 验证条件 | 通过标准 |
|---|--------|----------|----------|
| 1 | FIFO 排队 | 3 任务提交后，只有 1 个 running，其余 pending | running=1, pending=2 |
| 2 | FIFO 顺序 | 第 1 个完成后第 2 个开始 | 顺序执行 |
| 3 | 不丢弃 | 排队任务最终全部完成 | 最终 3 个都 completed |
